## Description

**PlateFaction**, by **Syntaxucre**, adds faction indicators to the default Blizzard player nameplates in **WoW Forever 1.60.1**.

### Features

- Choose faction icons, faction name colors, or both.
- Show Alliance and Horde icons independently. For Horde icons only, disable **Show Alliance icon**.
- Use blue names for Alliance and red names for Horde. Icon filters do not affect name colors.
- Place icons left, right, above or below the name, then adjust horizontal and vertical offsets.
- Set icon size from 10 to 64.
- Share preferences across your characters, with changes applied immediately.
- Keep Blizzard's health bar colors.
- No external addon dependencies.

Type **`/platefaction`** to open the options, or find PlateFaction under **Options → AddOns**. Enable the desired nameplates in WoW's settings first.

The interface automatically follows your game language: English, French, German, European Spanish, Latin American Spanish, Italian, Brazilian Portuguese, Russian, Korean, Simplified Chinese and Traditional Chinese. English is used as a fallback.

### Installation

Extract the release ZIP into your Forever client's `Interface/AddOns` folder so that `PlateFaction/PlateFaction.toc` is directly inside it. Restart WoW and enable PlateFaction in the addon list. For updates, `/reload` reloads the files.

### Compatibility

Designed for Blizzard nameplates and other players only. NPCs, pets and the personal nameplate are excluded. The addon respects hidden names, unavailable faction data and restrictions imposed by the game. Nameplate replacements such as Plater are not supported.

Forever is a beta client and its APIs may change. Automated checks use simulated APIs; multilingual rendering and combat behavior still need in-game validation. Translation corrections and bug reports are welcome on GitHub.
